# Eric Zou

20, 2nd year Electrical Engineering at Waterloo. 

The most ambitious problem I'm solving: I'm building the extraction layer of latent variables for AGI infrastructure.

External context, like email connectors, wallet connectors or world models, only captures humans' stated preferences, which is an act we all put on. Revealed preferences are how we actually think, feel and make decisions, and I think AGI has to start there, by pulling context from within.

<a href="https://github.com/EricJujianZou/llm-dream"><img src="assets/projects/llm-dream.webp" width="100%" alt="llm-dream"></a>

<a href="https://github.com/EricJujianZou/llm-dream"><b>llm-dream</b></a> asks whether an LLM can dream. I corrupted part of an agent's daily conversation log before it rewrote its memory each night, to test whether distorted replay helps it generalize the way the overfitted brain hypothesis says dreams do. It did not help in any of 30 runs. I submitted the paper to arXiv on October 14, 2026, and the write-up is on <a href="https://waterlooagi.com/experiments/llm-dream/">waterlooagi.com</a>.
